# CTCLossV2 · `+3.36` pts (`52.85 -> 56.21`)

> **Code Provenance**: Core V3 kernel rewrite landed in `a3a0ba9`; submitted SHA **`2b9d49d`** fixed the 256 B Level-0 `lossBuf` tail-overlap bug (`bad=48/9100 -> 0/9100`, sub `6afd6b8285ad43bbe0d8f48b`, rank `52 -> 47`).

## 1. Context & Bottleneck
After V2 (`0d5125c`, `52.85` pts), five per-step overheads remained inside the `T`-step DP recurrence:
1. Level-2 vector APIs emitted ~65 redundant SPR mask/mode setup instructions per timestep.
2. Active-window masking required `idxF`, `maskA`, `maskB`, `2x CompareScalar`, `And`, and `Select` (+2 `PipeBarrier<PIPE_V>()`s/step).
3. Full-row `-inf` `Duplicate` + `PipeBarrier` ran on every ring slot reuse (hurting wide `U=1201`: `198.14 us`).
4. Odd `U = 2S + 1` rows forced `H` separate unaligned `DataCopyPad` MTE3 stores per half-ring.
5. `FastSingle` (`N == 1`) stalled on scalar HBM reads of `input_lengths`/`target_lengths` before issuing `log_probs`/`targets` MTE2 loads.

## 2. Core Breakthrough Mechanisms
1. **Hoisted Normal Mask Mode (`SetMaskNorm() + ResetMask()`) + Level-0 `<T, false>` Intrinsics**:
   - Eliminates ~65 SPR instructions per timestep across all `T` steps.
2. **Contiguous `[s0, s1, s2]` Scratch Fusion**:
   - Packs `s1 = t0[wLen]` and `s2 = t0[2*wLen]` contiguously so `3x Exp` fuses into **1** `Exp<float, false>(..., 3*rep)` and `3x Sub` fuses into `2x Sub` via `bRepBcast` (`src1RepStride=0`) when `rep == 1`.
3. **2-Cycle Scalar Boundary Bitmask + Masked `Duplicate`**:
   - Invalid lanes inside `[cStart, cEnd)` occur only in the first/last 64-lane chunk; a 2-cycle scalar `inv` bitmask + `SetVectorMask` + `Duplicate<float, false>` + `ResetMask` replaces `2x CompareScalar + And + Select`, eliminating 2 `PipeBarrier<PIPE_V>()`s/step.
4. **Differential `[dirtyLo, dirtyHi)` Per-Slot Clearing**:
   - Clears only stale chunks outside `[cStart, cEnd)` in parallel with the 3 `Gather`s (`t650_c64_s600` `U=1201`: `198.14 -> 158.64 us`, **1.25x**).
5. **8-Row `Gather` Pack + 32B-Aligned MTE3 Burst (`offPack` + `packBuf0/1`)**:
   - For `saf <= 512` (`H = 8`), one `Gather` packs 8 odd-stride `U`-float rows into contiguous `8 * U` floats (guaranteed 32B-aligned), turning 8 unaligned `DataCopyPad` writes into **1 aligned `DataCopy`**.
6. **Cycle-0 Async MTE2 Prologue (`FastSingle`) + Overlapped Level-0 Tail Loss**:
   - Issues async MTE2 `DataCopyPad` for `il, tl, targets, log_probs` at cycle 0 overlapped with UB ring clearing & table init, and overlaps Level-0 tail loss with final MTE3 `log_alpha` drain.

## 4. Critical Precision & UB-Padding Invariant (`2b9d49d` Trap)
- **256 B Full-Repeat Overwrite Trap**: With hoisted `SetMaskNorm() + ResetMask()`, Level-0 `<float, false>` ops (`repeat = 1`) **always write a full 64-float (256 B) vector register**. When `lossBuf` was only `16` floats (`packBuf0 = lossBuf[16]`), overlapping tail `Exp/Adds/Ln/Sub` with async MTE3 drain of `packBuf0` silently corrupted the first `48` floats of `packBuf0` (`GATE_BAD bad=48/9100`). Padding `lossBuf` to `64` floats (`256 B`) resolved `bad=0/9100`, `GATE_PASS`, `34/34` extended + 3-run DET green.

## 5. Reusable KernelC Pattern
> **Rule (`dma-coalescing`)**: Hoist `SetMaskNorm()+ResetMask()` with Level-0 `<T, false>` intrinsics, fuse unary ops over contiguous scratch, pack `8` odd-stride rows via `Gather` into 1 aligned 32B MTE3 burst (`8 * U` floats), and **always pad every Level-0 destination buffer to a full 256 B (64-float / 128-half) repeat** whenever adjacent UB buffers are live on async MTE3.
