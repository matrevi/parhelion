# CTCLossV2 · `+15.67` pts (`37.18 -> 52.85`)

## 1. Context & Bottleneck
`CTCLossV2` runs `T` sequential forward dynamic-programming steps over `U = 2S + 1` states per sample (`states <= 2048`). In `v1` (`02c2048`, `37.18` pts), every time step `t` computed across the full padded state width `[0, saf)`, mutated gather offset tables via `Adds`, and waited synchronously on `VM3` + `M3V` barriers to flush each `log_alpha[t]` row to GM.

## 2. Core Breakthrough Mechanisms
1. **Active 64-Lane Window Slicing + Fused Masking**:
   Restricts `Gather`, `Max/Sub/Exp/Add/Ln`, `CompareScalar`, and `Select` at step `t` strictly to the 64-lane-aligned active state band `[cStart, cEnd)` covering `[start(t), end(t))`. Combines both boundary `CompareScalar` bitmasks via `And` so only **1 `Select`** (and 1 `set_cmpmask` barrier instead of 2) runs per time step.
2. **Immutable Gather Tables + Hardware `srcBaseOffset`**:
   Places a dedicated 32B-aligned 8-float `-inf` guard before every DP row slot (`slotStride = saf + 8`) and passes `rowInTile * lpRowBytes` via `Gather`'s scalar `srcBaseOffset`, eliminating per-step `Adds(offBC)` and `Adds(offP)` vector table rewrites even when `classes % 8 != 0`.
3. **Two-Half-Ring Async MTE3 Drain (`2 * H` Slots)**:
   Separates scratch `t0` from read-only `prev` slots so `MTE3` drains half-ring `0` (`H = 8` rows) to GM `log_alpha` asynchronously while `PIPE_V` computes half-ring `1`, removing `T` serial `VM3/M3V` stalls.
4. **Double-Buffered Multi-Row `log_probs` Prefetch (`lpt0` / `lpt1`) + External `TPipe`**:
   Streams `log_probs` tiles on `MTE2` concurrently with `PIPE_V` DP steps; `TPipe` lives outside `Kernel` so `compiler` promotes loop scalars to registers.

## 3. Precision & Synchronization Invariants
- Preserves hardware `vmax(-inf, -inf) -> 0.0f` pairwise order (`Max(s, s-1)` then `Max(..., s-2)`) and in-chain `PipeBarrier<PIPE_V>()` required by `ops_legacy` TIK `CTCLossV2`.
- Eliminates the 16 MB workspace fallback (`workspace = 1024 B` across all `S <= 1000` shapes).

## 4. Reusable KernelC Pattern
> **Rule (`async-pipeline`)**: In sequential time-step DP kernels where step `t` depends on step `t-1` in UB, decouple GM output writes into a `2 * H` UB ring buffer so `MTE3` bursts `H` completed rows asynchronously while `PIPE_V` advances unimpeded on the other half-ring, and slice vector width to the mathematically reachable diagonal band `[cStart, cEnd)`.
