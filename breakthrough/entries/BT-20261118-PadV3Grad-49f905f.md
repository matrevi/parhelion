# PadV3Grad · `+10.78` pts (`29.60 -> 40.38`)

## 1. Context & Bottleneck
`PadV3Grad` sums all input preimages folding onto each output coordinate under `reflect`, `symmetric`, `circular`, `edge`, or `constant` boundary rules. Treating `R`-dimensional preimage enumeration naively folded inner `W` margins repeatedly for every outer/row preimage combination and issued separate per-row `DataCopyPad` GM reads (`29.60` pts).

## 2. Core Breakthrough Mechanisms
1. **Host + Kernel Canonical Dimension Collapsing**:
   Drops unit dimensions (`n_d = m_d = 1`) and fuses adjacent unpadded dimensions (`front_d = back_d = 0`) into a single contiguous axis, collapsing 4D/5D `NCHW`/`NCDHW` spatial padding tensors directly into canonical 1D/2D/3D forms with zero data movement.
2. **Separable Kronecker Folding (`y = (F_0 ⊗ ... ⊗ F_{R-1}) x`)**:
   Folds outer and `H` row margins into UB accumulator planes **first**, so innermost `W`-margin `Gather<float>` folding executes **only once per output row** instead of once per input preimage group.
3. **4-Regime Specialized Execution Dispatch**:
   - *Regime 1 (Pure Copy / Constant Slice)*: Direct native-`T` `MTE2 <-> MTE3` double-buffered stream without `fp32` cast.
   - *Regime 2 (Column-Chunked Wide Parallel)*: Splits `(row, colTile)` across all 40 AIV cores when `M > 10000` or `rows < cores`.
   - *Regime 3A (Whole-2D-Plane Batch)*: Single contiguous `DataCopyPad` (`P * M_H` rows) + in-UB `H` folding + `Gather<float>` `W` folding with a guaranteed `0.0f` dummy slot at column `M`.
   - *Regime 3B (Row-Tiled General)*: Coalesced contiguous `H`-run batches accumulated into `planeAcc` in `fp32` before single-pass `W` fold.
4. **Byte-Weighted Core-Count Model (`SetBlockDim`)**:
   Scales active AIV blocks at `~16 KB` effective work per core, avoiding 40-core dispatch overhead on tiny tensors while saturating all 40 AIVs on large shapes.

## 3. Precision & Synchronization Invariants
- Passed **340/340 extended cases** across `reflect`, `symmetric`, `circular`, `edge`, and `constant` modes (`fp32` & `fp16`), retaining scalar Kahan fallback for negative paddings or extreme outer multiplicity (`> 96`).

## 4. Reusable KernelC Pattern
> **Rule (`separable-folding`)**: For multi-axis linear stencil/scatter-add operators (`y = (F_0 ⊗ ... ⊗ F_{k}) x`), collapse unpadded/unit axes first and factor outer/row reductions in UB before touching sub-32B inner-axis `Gather` operations — cutting unaligned inner-axis work by the product of outer multiplicities.
