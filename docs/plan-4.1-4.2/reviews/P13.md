# P13 审查记录

结论：**已合入**（2026-11-26，`1f035b3`）。下面是跟进项，不需要在 `impl/P13-bound-output` 上返工。

## 主会话已在 main 上修的

1. **`agent_messages` 与 `kb_query` 的翻页走不完。** 两处都把 `total` 算成 `offset + len(rows)`，可 `rows` 是从第一条取起的整段，于是越翻越大：最后一页之后 `next_cursor` 一直指向同一个空页。原测试只限定最多翻 20 或 10 页、再比对看到的条目，所以没发现。现在 `kb_query` 用 `len(results)`；`agent_messages` 取满一页时多给一页，空页即结束。测试改为断言翻页会结束、调用次数正确。
2. **`agent_messages` 首页会把一条没给出去的消息标成已读。** 原来多取一行用于判断还有没有下一页，而读取会确认它返回的每一行。现在首页只取本页的行，确认范围与展示范围一致，测试断言确认到第 50 条为止。
3. **`bound_output` 出错不再让工具调用变成协议错误。** `mcp/server.py` 捕获异常，回退为原始 JSON。
4. **`parhelion_agent_peek` 的输出预算压到上限以内**（P08 原为 8000 字节，高于 5000 的上限，会被整段落盘），见 `reviews/P08.md`。

## 跟进
