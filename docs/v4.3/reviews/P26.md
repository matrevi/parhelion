## 核对过的

- **席位身份。**
  - 总线 `agents` 表增加 `seat` 列，类型为 `TEXT NOT NULL DEFAULT ''`。
  - 旧代码按列名读取（`sqlite3.Row`），新进程打开库时补上的列不影响仍在跑的旧守护进程。
  - 旧的 `.worktrees/sprint-<axis>` 布局仍能识别。
- **远端根目录**移到了 `device_env.contest_work_root`，默认回落到 `work_root`。主会话核对过：本机配置的 `work_root` 与原来写死的路径相同，线上行为不变。`runtime/npu-test.py` 的改动只用标准库。
- **同题并发。** 这一项按真机核实得出「不覆盖」，所以没有启用席位级隔离：
  - 参考模板路径每次运行都在独立的临时树里编译；
  - 构建路径与 legacy 路径按题加 flock，串行执行；
  - 真机上同题两个 SHA 同时跑 smoke，结果各自对应自己的 SHA。
- **角色与契约。**
  - `recon` 与 `knowledge` 子角色的工具表都更短，有字节测试覆盖。
  - 四段角色契约都在 1500 B 以内，末行保留了数据通道说明。
- **换席。**
  - 换席按 stagnation 事件幂等：同一批回执重放返回 `existing`。
  - `agents.auto_replace_on_stagnation` 默认关（D4）。
  - `enable_auto_submit` 的语义没有变。
